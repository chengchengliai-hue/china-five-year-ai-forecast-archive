# 2026—2031年中国普通居民五年结构预测：专家团综合报告

信息截止：2026年7月20日23:59（Asia/Shanghai）；实际执行：2026年7月24日；预测终点：2031年7月20日。

本报告综合四位相互独立专家的完整判断。这里的“普通居民”指主要依靠本人或家庭劳动收入、没有大量资本、特殊权力、内部信息或稳定被动收入的人。综合过程不以多数票代替论证：共同结论被视为稳健基线，少数意见被保留为需要单独验证的分支，概率仅在注册表中作为未来评分工具。

## 一、综合判断

到2031年，中国普通居民最可能生活在一个“总量和生产率继续增长、现金购买力温和提高，但优质机会与安全感改善更慢”的环境。它不是普遍生活水平下降，也不是产业升级自然使每个人受益。日常商品、部分数字服务和无房者的居住可负担性可能改善；与此同时，居民越来越依赖劳动收入而非资产升值，获得稳定、匹配、收入合理且有成长空间的工作会更难，家庭的养老医疗协调和无偿照护时间会成为新的硬约束。

这一判断不把2026年上半年增速线性外推五年。它依赖几组移动较慢的结构关系：人口减少与老龄化；房地产由增量开发转向存量居住和分化；土地相关收入与地方公共服务能力的调整；高校毕业生大量进入而初级白领任务被技术重组；先进制造、数字化和低碳基础设施积累形成大量设备存量；外部市场碎片化与中国企业适应能力同时存在。2025年60岁及以上人口已达3.2338亿，[国家统计局人口资料](https://www.stats.gov.cn/xxgk/jd/sjjd2020/202601/t20260119_1962338.html)使照护需求成为比短期景气更稳的变量；2026届高校毕业生预计1270万，[教育部资料](https://www.moe.gov.cn/jyb_xwfb/s5147/202606/t20260615_1440719.html)又意味着“劳动力总量下降”不会自动缓解高学历入口竞争。

对一个普通家庭而言，五年后的核心变化可概括为四个转向：收入从“工资加房产重估”转向更依赖持续劳动和技能溢价；职业从“学历对应岗位”转向“领域知识、AI协作、现场交付和结果责任”的组合；城市选择从追逐房价转向比较岗位密度、租住成本、通勤和医疗教育照护；家庭负担从显性的买房育儿支出，部分转向养老医疗、照护时间、职业中断和迁居困难。

## 二、四位专家的共同结论

第一，四位专家均判断实际购买力到2031年更可能温和改善，而非普遍下降，但中位家庭体感会弱于产出或平均收入数字。2026年上半年居民收入实际增长4.2%，消费支出实际增长2.7%，财产净收入仅增长1.1%，[国家统计局居民收支数据](https://www.stats.gov.cn/sj/zxfbhjd/202607/t20260715_1964129.html)显示现金收入、消费意愿和资产感受并不同步。未来是否真正改善，要看中位数、低收入组和必要支出，而非只看人均GDP。

第二，四位专家都区分“有工作”与“有合适工作”。总量就业可能保持基本稳定，养老服务、制造运维和本地服务也会创造岗位；但稳定合同、合理工资、专业匹配和成长阶梯很可能更稀缺。企业在需求偏弱时采用AI和自动化，往往先用于降本、少招新人和扩大骨干员工管理跨度。2026年上半年固定资产投资下降5.7%、民间投资下降8.5%，[国家统计局投资数据](https://www.stats.gov.cn/xxgk/sjfb/zxfb2020/202607/t20260715_1964124.html)说明产出增长与企业扩岗意愿不能画等号。

第三，能力价值将明显重估。共同升值的不是抽象的“懂AI”，而是能将工具嵌入真实业务，发现问题、核验结果、处理例外并承担安全、客户或商业责任的能力。设备诊断、工艺质量、工业软件实施、数据核验、复杂销售、供应链协调、照护沟通和合规安全更重要；模板写作、资料搬运、基础制图、重复录入、简单客服和只凭通用学历的信号价值下降。

第四，产业成功不等于普通劳动者普惠。高技术制造、装备制造、数字产业和能源基础设施仍会扩张。工信部资料显示2026年上半年装备制造、高技术制造增加值分别增长9.3%和13.3%，规上制造企业AI应用超过30%，但同一资料也指出“供强需弱”，[工信部半年资料](https://wap.miit.gov.cn/xwfb/bldhd/art/2026/art_bc4cf76777cb4fd2896082ca2ff7039d.html)恰好说明产值、利润、就业和工资需要分别验证。真正可能广泛吸收居民劳动的，是先进设备的安装运维、质量检测、节能改造，以及养老康复、维修物流、企业服务等必须在现场完成的环节。

第五，住房不再是普遍可靠的财富跃迁工具。2026年上半年房地产投资下降18.0%、销售面积下降11.6%、新开工下降23.4%，[国家统计局房地产数据](https://www.stats.gov.cn/zwfwck/sjfb/202607/t20260715_1964126.html)只能作为结构调整的起点，不能机械推出2031年价格。专家共识是城市间进一步分化：强产业和公共服务节点仍有稀缺性，人口流出地区的住宅更可能“住得起、卖不动”。低价帮助新购者，也会伤害高杠杆存量业主的净资产、换城和创业能力。

第六，地区机会继续集聚，但不等于只有一线城市获胜。城市群、强省会、先进制造节点、口岸和少数有特色产业的县域都可能形成机会；缺少产业密度、人口流入和财政能力的中小城市更难同时提供职业成长、房产流动性与高质量公共服务。家庭是否迁移还取决于老人医疗、儿童照护和亲属网络，最高名义工资并不总是最优选择。

第七，外部环境总体构成温和负面约束，而非单向崩塌。关税、技术限制、合规成本和海外本地化会压缩部分国内岗位增量；市场多元化、国产替代、数字服务和绿色产品需求又会缓冲。WTO资料显示贸易碎片化与部分新需求并存，[WTO贸易展望](https://www.wto.org/english/news_e/news26_e/stat_19mar26_329_e.htm)。普通居民最终感受到的是订单、加班、奖金、供应商账期、工厂选址和地方财政，而不是抽象的贸易总额。

## 三、四位专家的关键分歧

最大的分歧是AI对劳动者净福利的方向。三位专家把它判断为“结构重组、福利混合”：熟练者得到增强，入门任务被替代，是否受益取决于工资分享、在岗培训和责任位置。反方专家则进一步判断为“温和恶化”，理由是五年内企业更可能先压缩新人岗位、扩大管理跨度和强化监控，而劳动制度调整滞后。ILO研究支持“多数职业先改变任务组合而非整体消失”，[ILO生成式AI与就业研究](https://www.ilo.org/publications/generative-ai-and-jobs-2025-update)，但这并不能回答生产率收益由谁获得。因此P09必须同时验证新人招聘、工时、工资和每名管理者覆盖人数，不能只看职业是否消失。

第二个分歧是哪些产业算“普惠”。长期结构专家和反方专家相对乐观，认为服务消费、设备存量和照护需求可以带来温和改善；产业和居民专家更强调结构混合，认为康养、维修和物流即使增加大量岗位，也可能形成低薪、高强度、弱保障的职业群。分歧不在需求是否存在，而在支付机制、采购价格、职业阶梯和社保能否把需求转成好工作。

第三个分歧是房地产调整的福利含义。所有人同意住房功能变化，但居民专家更强调存量家庭的财富、迁移和代际支持受损；结构专家相对强调新进入者门槛下降和住房回归居住属性。综合判断不把房价涨跌直接当福利：同一价格下降对无房青年是改善，对高杠杆中年家庭可能是恶化，对人口流出城市则可能主要表现为流动性消失。

第四个分歧是外部适应的国内就业含量。产业专家认为市场多元化、核心零部件和复杂制造可保留一部分高价值岗位；反方专家提醒，“保企业全球收入”不等于“保国内岗位”，海外设厂和第三地组装可能在维持出口份额的同时外移劳动密集环节。这一分歧要求2031年除看出口额，还要看国内增加值、国内外雇员比例和供应商工资。

## 四、P01—P12综合预测

**P01｜实际收入与购买力：温和改善，但分布不均。** 生产率提高、部分服务扩张和日常商品降本提供支撑；房产财富效应转弱、照护支出和就业不稳定抵消部分收益。稳定技能工、专业服务者和无高额房贷的新进入者改善较明显；低议价服务劳动者、地产链从业者、负债业主和照护家庭改善较弱。2031年以实际可支配收入中位数、低收入分位数、工资性收入、必要支出占比和消费率共同判定。

**P02｜获得并保持合适工作：温和恶化。** 不是预测普遍失业，而是岗位质量与居民要求的组合更难获得。毕业生供给、企业固定成本谨慎、入门任务自动化和地区集聚共同提高门槛；熟练技工、照护人员和具备行业经验者相对稳。若服务业和小微企业形成大规模正规岗位、青年求职时长与入职工资同时改善，则本判断失败。

**P03｜能力价值：发生结构性重估。** “专业知识＋AI协作＋现场交付＋复杂沟通＋结果责任”升值；标准化信息生产和缺乏实际产出的通用证书贬值。普通人不必都转为程序员，但需要能用工具完成可验证成果。验证应比较技能工资溢价、招聘要求、真实项目经历回报和职业认证后的工资轨迹。

**P04｜职业家族：有增有减，入门层先变化。** 扩张方向包括设备安装运维、工艺质量、工业软件实施、能源电网、安全合规、康养医疗辅助、维修物流和复杂客户服务；收缩或降质方向包括房地产增量开发链、重复行政、基础内容、简单客服、部分初级财会与编码。职业名称可能保留，人数、初级席位和任务构成却会改变。

**P05｜广泛惠及劳动者的产业：在“存量运维与生活服务”，不一定在产值冠军。** 先进制造和AI提供上游能力，真正扩散就业更依赖安装、售后、运维、检测、节能改造和中小企业数字服务；养老康复、托育、维修、物流也能广泛吸收劳动。其最大失败条件是低支付、平台压价和弱社保把需求变成大量低质量岗位。验证必须同时看就业弹性、中位工资、工时、合同和社保。

**P06｜住房：从普遍增值工具转为分化的居住与流动性资产。** 核心产业节点和优质公共服务区域仍可能保持稀缺性；人口流出地和同质化新区的成交与变现困难更重要。无房青年可能因租购成本下降受益，存量家庭可能因净资产、抵押和换城能力下降受损。应以分城市房价收入比、租金负担、成交周期、人口净流入和住房资产占家庭财富比验证。

**P07｜家庭负担：货币项目部分缓解，照护时间总体加重。** 少子化降低一部分家庭的教育总量，托育、医疗和养老政策也可能扩容；但老龄化会增加陪诊、康复、失能照护和跨城协调。真正稀缺的是能覆盖工作时段、价格可负担且人员稳定的服务。若长期护理、托育和社区医疗显著降低无偿照护时长与照护者退出就业，本判断应上修。

**P08｜地区机会：进一步向城市群、强省会和专业产业节点集中。** 机会不只按行政等级排列，而沿研发、制造、物流、能源、医疗和特色服务网络分布。部分县域可成为赢家，多数收缩型小城则面临岗位、住房流动性和公共服务的共同压力。迁移能力本身成为优势；承担照护者即使技能相同，也可能被家庭位置限制。

**P09｜技术作用：基线为任务重组和福利分化，同时保留偏负分支。** AI会提高熟练员工、小企业主、医生教师和技术工的效率，也会减少资料整理、初稿、录入和低风险练习岗位，并可能强化量化管理。不能用“没有整类职业消失”证明劳动者受益。2031年应比较AI高使用企业的新手招聘、团队规模、工时、工资、培训和劳动报酬占生产率收益的比例。

**P10｜向上流动：传统路径弱化，新路径更依赖可验证能力和转换资本。** “一般学历—普通白领—买房升值”的稳定链条变弱；可认证技能加现场经验、行业知识加AI工具、沿产业节点迁移、在康养维修和企业服务中建立复购关系更现实。新路径仍要求学习时间、迁移能力和家庭托底，因此并非天然更公平。

**P11｜外部环境：温和恶化，但由适应能力缓冲。** 贸易和科技限制、海外本地化及全球风险提高成本并减少部分国内低技能岗位；市场多元化、国产替代和核心制造能力避免基线演变为全面失速。普通居民的暴露高度集中于沿海出口链、受限技术行业、供应商和相关地方财政。验证必须区分企业全球收入增长与国内岗位、工资是否增长。

**P12｜三个最容易被低估的变化。** 第一，AI最早、最深的职业影响可能是抽走新人的练习任务与师徒台阶，五年后表现为人才断层而非当期失业。第二，设备、能源和建筑存量扩大后，“维护、改造、安全、合规”的就业价值可能超过继续新建。第三，老龄化把家庭成员的时间变成稀缺生产要素，并影响女性与中年人的工时、晋升、迁移和收入。反方专家另加一个重要分支：海外本地化可能保住中国企业，却减少国内劳动密集岗位。

## 五、支持这些判断的主要因果链

第一条是居民资产负债表链：房地产增量开发收缩 → 家庭财富效应和抵押能力下降、地方土地相关收入承压 → 居民增加流动性偏好，部分地区公共服务和建设扩张受限 → 消费与小企业需求恢复慢于产出 → 就业质量和工资改善有限。政策若能由中央财政、社保统筹和服务支出替代土地财政，这条链会减弱。

第二条是产业—职业链：研发、设备、数字和能源基础扩大 → 大企业先自动化标准任务并提高单位人员产出 → 研发、工艺、质量、实施和运维增加，重复文职与低阶信息岗位减少 → 产值增长快于就业增长 → 收益集中到稀缺复合技能和资本，除非中小企业需求、劳动议价和在岗培训同步增强。

第三条是人口—家庭链：出生减少与老龄人口增加 → 新增住房和教育总量减弱，医疗、康复、养老和社区服务需求增强 → 有偿照护岗位增多，但家庭支付能力和服务人员稳定性不足 → 大量需求仍由家庭成员无偿承担 → 中年人、女性和独生子女家庭减少工时、拒绝迁移或中断职业，实际福利低于收入数据。

第四条是地区集聚链：高价值岗位和公共服务向产业节点集中 → 青年和技能劳动者迁移 → 流入地租住、通勤和照护成本上升，流出地人口、住房流动性和财政基础变弱 → 同一职业因城市与家庭约束产生不同回报。远程工具能降低部分交易成本，但难替代现场生产、信任网络和优质公共服务。

## 六、外部因素如何传导到普通人

外部冲击通过五条路径进入家庭：关税和贸易救济影响订单及利润；出口管制增加设备、研发和合规成本；海外本地化改变国内外产能和雇员分布；能源、航运和气候冲击改变生活成本；金融与汇率变化影响企业融资和地方收入。企业会通过转市场、国产化、自动化和海外设厂适应，但适应成本可能表现为更低供应商价格、更长账期、更少国内增员、更高工作强度，而不是企业直接消失。

可再生能源装机到2026年4月底已占总装机60.5%，[国家能源局资料](https://www.nea.gov.cn/20260616/ab30f2b505764d13972ac14e7d3ffeed/c.html)提高了长期能源缓冲并创造运维需求，但不能消除极端天气、关键矿产和电网协调风险。世界银行提出通过社会保障和消费再平衡降低预防性储蓄，[世界银行中国经济更新](https://www.worldbank.org/en/news/press-release/2026/07/07/rebalancing-growth-china-economic-update)说明国内制度选择能够缓冲外部冲击；它仍是需要实现的条件，不能提前算作居民成果。

## 七、最可能推翻报告的变化

最强乐观推翻情景是：房地产库存与地方债务完成有序调整，中央财政和社保统筹明显加强，托育养老形成可负担服务，居民消费率上升；服务业和小微企业恢复投资；AI生产率被广泛分享为工资增长、工时下降和在岗培训；外部限制反而推动高价值环节留在国内。若中位数实际收入持续快于生产率、青年求职时间下降、正规服务岗位明显增加且家庭无偿照护减少，本报告明显偏保守。

最强悲观推翻情景是：房地产与地方财政相互强化下行，外部冲突阻断能源、航运或关键技术，自动化快于新岗位生成，公共照护又无法扩容。届时收入、就业、住房与公共服务可能同步恶化，而不只是分化中的温和改善。公共卫生事件、重大技术突破和极端气候也可能改变基线。

还有一个方法性失败条件：现有统计不足以观察求职时长、入职工资、非自愿灵活就业、无偿照护时间、初级任务比例和海外雇员变化。如果2031年仍只用GDP、平均收入、出口和失业率评分，项目会把“可测量”误当成“居民真实福利”，即使预测文本本身合理，也无法得到可靠结论。

## 八、2031年验证与评分

验证窗口设在2031年7月20日前后，优先使用2026—2030完整年度数据，并在可获得时补充2031年上半年数据。所有指标须采用当时可追溯的同口径序列；若统计口径修订，保留旧值、修订值和转换说明。政策出台不等于结果实现，产值增长也不等于劳动者受益。

最低评分集包括：居民可支配收入中位数和分位数的实际增速、工资性收入与消费率；分年龄求职时长、入职工资、合同期限、工时、社保连续性和三年工资成长；分职业就业人数、中位工资、初级岗位比例与晋升率；分行业增加值、利润、就业弹性、劳动报酬和供应商账期；分城市租售负担、成交周期、人口净迁移和公共服务可达性；家庭教育医疗养老自付、无偿照护时长与照护者劳动参与；AI使用企业的新人招聘、团队规模、生产率和工资；出口国内增加值、目的地分散度、海外产能与国内外雇员比例。

每个P项先按预注册方向判定结果，再分别评价方向、量级、时间和因果解释。无法取得关键数据时标为“无法判定”，不得事后换成有利指标。概率评分采用四位专家独立概率的中位数，并保留单个专家分数与分歧标签。这样，2031年既能回答“综合判断是否正确”，也能检查哪一种专家视角在何种问题上更有预测力。
